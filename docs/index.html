Why revelio

Built for what project scanners miss

Project-scoped tools stop at your lockfile. Revelio starts where those leave off — the machine itself.

🖥

Host-scoped inventory

Enumerates what is actually installed via brew list, pip list, gem list, and more — not what a lockfile says should be there.

🔀

Cross-scanner fusion

Runs OSV, npm audit, pip-audit, cargo-audit, and Grype in parallel, then deduplicates findings by canonical identity — one advisory per CVE, not five.

⚡

Actionable attribution

Maps each vulnerable transitive dependency back to the direct install you can actually upgrade, with a ready-made command and fix rationale.

✓

No cloud, no account

A standalone Bash script with no agent, no SaaS subscription, and no data leaving your machine. Fully offline in inventory mode.

Quick start

Up and running in seconds

No build step. No install script. Clone and run.

1

Requirements

macOS or Linux, bash 4+, jq, curl. On macOS run brew install bash jq — the system Bash 3.2 is not supported.

2

Clone the repo

No build step required. The CLI runs directly from the cloned directory using the scripts in place.

3

Run a scan

Inventories all managers, checks for outdated packages, queries OSV and other vulnerability sources, and prints a colour-coded summary.

4

Schedule it

Use revelio schedule install for recurring scans via launchd (macOS) or systemd-user / cron (Linux).

bash
# Clone
git clone https://github.com/a-magdy/revelio.git
cd revelio

# Full vulnerability scan
./revelio.sh scan

# Inventory only (offline)
./revelio.sh inventory --offline

# Explain why something is installed
./revelio.sh why openssl@3

# Compare two runs over time
./revelio.sh diff ~/.revelio/run-a ~/.revelio/run-b

# Schedule daily scans
./revelio.sh schedule install --cadence daily
